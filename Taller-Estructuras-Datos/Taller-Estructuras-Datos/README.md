## Nombre del estudiante

## Descripción
Taller desarrollado en Java para practicar estructuras de datos unidimensionales, bidimensionales y `ArrayList`.

El proyecto contiene 15 ejercicios organizados en paquetes:

- `arreglos`: ejercicios 1 al 5.
- `arraylist`: ejercicios 6 al 10.
- `matrices`: ejercicios 11 al 15.

Se aplican conceptos de programación orientada a objetos, métodos, encapsulamiento, reutilización de código, KISS y DRY.

## Requisitos
- Java JDK 17 o superior.
- Ejecución desde consola.

## Instrucciones para ejecutar
1. Abrir la carpeta `Taller-Estructuras-Lineales`.
2. Verificar que Java esté instalado.
3. Abrir una terminal.
4. Compilar:

```bash
javac -d out src/Main.java src/arreglos/*.java src/arraylist/*.java src/matrices/*.java
```

5. Ejecutar:

```bash
java -cp out Main
```

## Ejercicios incluidos

1. Primeros 10 números primos.
2. Primeros 100 números pares.
3. Factoriales de números aleatorios.
4. Número menor y mayor.
5. Inversión de números.
6. ArrayList hasta obtener el número 10.
7. Inserción ordenada y eliminación.
8. Frecuencia de números del 1 al 20.
9. Ordenamiento y separación de pares e impares.
10. Gestión de partidos de fútbol.
11. Búsqueda en una matriz.
12. Sumatoria de la diagonal opuesta.
13. Matriz simétrica y esquinas.
14. Matriz transpuesta.
15. Intercambio de primera y segunda fila.
